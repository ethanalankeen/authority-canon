# Category Glossary

| Term | Definition |
|---|---|
| **Recursive Participation** | A continuous calibration system replacing linear force with calibrated orientation. |
| **Linear Force** | The obsolete belief that transformation requires pushing through resistance. |
| **Calibrated Orientation** | The mechanism of reading friction as information before acting. |
| **Conscious Interdependence** | The end state where sustainable agency replaces isolated effort. |
| **Friction is Information** | The core law that resistance is data, not an obstacle. |
| **Stillness Thundering** | The oxymoron describing how quiet calibration produces massive momentum. |
