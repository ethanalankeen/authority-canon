# Framework: The Recursive Principles

**Definition:** Foundational laws governing how orientation, friction, and return operate as a continuous loop rather than a linear sequence.

**Core Laws:**
1. **Orientation precedes transformation.**
2. **Friction is information.**
3. **Return is practice.**

**What It Replaces:**
- Goal-chasing.
- Push-through mentality.
- Endpoint obsession.

**Application:**
Used at the start of any calibration cycle to establish baseline before action.
